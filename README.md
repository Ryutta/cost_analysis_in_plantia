# Cost Analysis by Plantia

本プロジェクトは、設備保全管理システム（Plantia）のデータや関連するコスト・リスクデータを統合し、保全コストの分析と最適化を行うためのPower BIプロジェクトです。

## どんなデータを扱うか
主に以下のデータを統合して分析します。
- **Plantia保全データ**: 設備リスト、保全サイクル
- **コストデータ**: 購買明細、予実管理（予算と実績）、起業費・修繕費
- **リスク評価データ**: 設備ごとのリスク評価（2023〜2025年）
- **マスタデータ**: プラント略号辞書、専門区分

## どんな見せ方をするか
Power BIのレポート機能を用いて、多角的に可視化します。
- **指標の切り替え**: 件数や金額、単位を動的に切り替えて表示
- **予実の比較**: 予算に対する実績の推移や差異のダッシュボード化
- **属性別分析**: プラント別、専門区分別、リスク評価別のコスト集計やドリルダウン
- **時系列分析**: 年度・月別のコストトレンド表示

## 活用の仕方
- **保全コストの最適化**: 購買明細や修繕費の傾向を分析し、無駄の削減やコスト削減の機会を特定します。
- **リスクベースの意思決定**: 設備のリスク評価と保全コストを掛け合わせ、優先的に予算を割り当てるべき設備の特定や、過剰保全の見直しに役立てます。
- **予実管理の高度化**: 予算と実績を定期的にモニタリングし、予算超過リスクの早期発見と軌道修正を実施します。
